# Recruiter 5-Minute Route

## 1. Start with the executive summary

Open `reports/executive_summary.md` to see the business-facing readout, key numbers and recommendations.

## 2. Review the workbook

Open `dashboard/campaign_dashboard.xlsx` and scan:
- Dashboard
- Channel Analysis
- Landing Pages
- Source Data

## 3. Review the A/B test

Open `reports/ab_test_marketing_uplift.md` to see the A/B test readout: conversion uplift, 95% confidence interval, p-value, Bayesian probability and rollout recommendation.

## 4. Check SQL evidence

Open `../../sql/SQL_EVIDENCE.md` for 10 reviewer-friendly queries covering joins, CTEs, window functions, funnel, cohort, CRM lifecycle, attribution logic, ranking and KPI aggregation.

## 5. Check BI evidence

Open `../bi/README.md` for the Power BI semantic model/report spec, Tableau workbook skeleton and dashboard screenshot route.

## 6. Check KPI logic

Open `docs/kpi_dictionary.md` to confirm that CTR, CPC, conversion rate, CPA and ROAS are defined clearly.

## 7. Check boundaries

Open `docs/assumptions_and_limits.md` to confirm that this is simulated-data portfolio work and does not claim real advertising, client, CRM, GA4 or user-level account access.
